# 作品列表布局原型

这是 LunaDeerMC 新视觉系统的独立原型，仅用于确认“作品列表”页面的布局与交互，不会改动正式站点。

## 已确认的方向

- 采用第三套方案：桌面端为左侧作品目录、右侧详情舞台的主从布局。
- 浅色模式沿用“白天牧场”配色，深色模式沿用“黄昏红石工坊”配色。
- 目录图标统一使用 Lucide 线性图标，不使用 Minecraft 方块或体素风图标。
- Minecraft 场景只出现在作品封面等大面积内容视觉中。
- 移动端改为“目录在前、详情在后”的自然纵向阅读顺序。

## 可体验的交互

- 搜索作品
- 按分类筛选
- 切换当前作品并查看详情
- 切换日间 / 夜间主题
- 展开与关闭工具菜单
- 移动端选择作品后自动滚动至详情

当前作品名称、版本、下载量和描述均为布局验证用的示例数据，不代表正式内容。

## 本地运行

```bash
npm install
npm run dev
```

请以 Vite 启动后输出的地址为准；本轮评审实例运行在 <http://127.0.0.1:5174/>。
