# Homepage Duskmoon Prototype

这是首页视觉讨论阶段的概念原型，不是 LunaDeerMC 正式网站工程，也不是已批准的视觉稿。

## 已验证的意图

- 首页由一个统一的四层 Minecraft 场景构成。
- 向下滚动时应当远景慢、近景快地向上移动，形成视角降低的感觉。
- 最前景主体色应当无缝延续为“精选作品”区的实心背景。

## 已知问题

- 当前图层速度关系和滚动体感不正确。
- 当前图片的画风、构图和质量未通过视觉确认。
- 各层并非来自真正统一的场景和机位，透视、地平线与景物无法严密对齐。
- 深色前景形成横向矩形带，滚动时像遮罩切片。
- 地块呈悬浮岛式断面，没有形成连续的视角降低效果。

现有图片、颜色值、速度参数、作品区排版和代码实现均不可作为正式设计依据。保留此目录的唯一目的，是证明交互概念已经被正确理解，并为后续讨论提供反例。

正式首页结论以 `design/homepage-visual-direction.md` 和 `design/motion-system.md` 为准。
