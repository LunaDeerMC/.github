# Homepage Theme Lab

用于确定 LunaDeerMC 新主页视觉气质与语义配色的独立原型，不是正式站点实现。

## 本轮比较内容

- **白天牧场**：明亮、自然、亲和；绿色承担主要操作强调色。
- **黄昏工坊**：沉稳、温暖、技术感；红石红承担主要操作强调色。
- 两个主题共用完全相同的页面结构，切换时保留滚动位置。
- 首屏图片下沿与精选作品区使用一致的语义前景色，用于验证场景到内容舞台的自然过渡。
- 右下角“查看色值”可展开当前主题的语义色板。

两套页面配色已于 2026-07-30 确认为后续设计基线。

## 原型边界

当前首屏场景是用于配色判断的合成图。最终主页仍将制作四层独立素材，并按照远慢近快的正确关系实现滚动视差；本原型不用于确认最终图片质量与运动参数。

## 本地运行

```bash
npm install
npm run dev
```
