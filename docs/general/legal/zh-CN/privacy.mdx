## 1. 适用范围

本政策适用于 LunaDeerMC 官方网站及其文档页面中由我们控制的内容和联系渠道。它不适用于 GitHub、爱发电、KeyAnchor、QQ、Modrinth、Minecraft 服务端平台、网站托管商或其他第三方服务；进入这些服务后，应以对应服务的隐私政策和用户协议为准。

本政策只说明目前的处理方式。某个作品、社区或外部服务如果有单独的隐私说明，应优先阅读该说明。

## 2. 我们可能接触到的信息

### 你主动提供的信息

当你通过邮件、GitHub Issue、QQ 群或其他公开/私下渠道联系维护团队时，你可能会主动提供：

- 姓名、昵称、邮箱、QQ 号或其他联系方式；
- 订单号、购买记录、授权信息或用于核验权益的资料；
- 问题描述、日志、配置片段、附件、设备或运行环境信息；
- 你在公开渠道发布的评论、Issue、代码、截图或其他内容。

我们只在回复咨询、处理技术支持、核验交易、维护社区秩序、处理安全问题或履行法律义务所必需的范围内使用这些信息。请在提交日志前删除密码、访问令牌、授权密钥、个人住址、支付卡号等与处理问题无关的敏感信息。

### 访问网站时产生的技术信息

网站托管商、CDN、网络运营商或相关基础设施可能按照其运行方式生成访问日志。日志可能包括 IP 地址、访问时间、请求路径、HTTP 状态码、浏览器及操作系统标识、来源页面等信息。我们无法决定所有第三方基础设施记录的字段、保存期限或处理方式；如需了解这些信息，应查看相应服务的政策。

截至本政策更新日，本站没有配置站内账户、站内评论、站内联系表单、在线支付后台或广告/分析型用户画像系统。站内搜索参数只用于页面内的搜索交互，不与本站账户绑定。

### 浏览器本地存储

为记住你的主题选择，本站可能在浏览器的 `localStorage` 中保存主题偏好；作品页面可能在当前浏览会话的 `sessionStorage` 中暂存 GitHub Releases 查询结果，以减少重复请求。这些内容通常只保存在你的设备或当前浏览器会话中，不用于建立本站账户或识别你的真实身份。清理浏览器站点数据会删除相应内容。

## 3. 信息的使用目的

我们处理直接收到的信息，主要用于：

- 提供、维护和改进网站、文档及作品；
- 回复合作、技术支持、退款或安全问题；
- 核验订单、授权和请求人的身份，防止滥用、欺诈和重复申诉；
- 诊断故障、保护网站和作品的安全与稳定；
- 遵守适用法律、监管要求或处理争议。

除非获得你的授权、法律要求或为完成你主动发起的服务所必需，我们不会出售你的个人信息，也不会以本站为名建立与网站使用无关的长期画像。

## 4. 信息的共享与第三方服务

本站的下载、代码托管、版本信息、付款、授权激活、文件提取和社区交流可能跳转至第三方平台。你在这些平台上提交的信息会直接由相应平台接收和处理，例如：

- GitHub 可能处理代码仓库、Issue、Release 查询及账户活动；
- 爱发电可能处理赞助、商品购买、订单和支付相关信息；
- KeyAnchor 可能处理授权激活、资源提取和一对一支持所需的信息；
- QQ、Modrinth、托管商、CDN 或其他服务可能按照自身规则处理账号、设备、日志和内容信息。

作品页面部分功能会由你的浏览器直接请求 GitHub API；该请求不是由本站服务器代理，GitHub 可能因此看到请求所需的网络和设备信息。我们不控制第三方服务的隐私实践、数据保留、跨境传输、账户安全或服务可用性。向外部平台提交信息前，请确认你了解其政策并只提供必要内容。

在下列情形下，信息也可能被提供给必要的服务提供商、专业顾问或主管机关：为提供你请求的服务、保护网站和用户安全、处理法律程序，或遵守具有约束力的法律要求。我们会在合理必要的范围内处理，不会将其用于无关目的。

## 5. 保存期限与安全措施

对于直接发送给维护团队的邮件、支持记录和交易核验资料，我们会在完成对应事项、处理潜在争议或履行必要的法律义务所需期间内保存；不再需要时，会删除、匿名化或停止使用。公开平台上的内容和账户资料，其保存期限由相应平台及用户自行管理。

我们会采取与团队规模和处理场景相适应的访问控制、最小化收集和安全管理措施，但互联网传输、电子邮件和第三方平台均不能保证绝对安全。请使用私下渠道提交必要资料，并避免在公开页面暴露凭据。

## 6. 你的权利与请求方式

对于你直接提供给维护团队的信息，你可以通过 [zhangyuheng@lunadeer.cn](mailto:zhangyuheng@lunadeer.cn) 联系我们，提出查询、复制、更正、删除、撤回授权或停止使用等请求。为保护信息安全，我们可能要求提供合理的身份或权益核验资料；核验资料只用于处理请求。

如果信息由 GitHub、爱发电、KeyAnchor、QQ 或其他第三方平台直接收集，相关查询、更正、删除、账户注销和支付记录请求应向该平台提出。法律要求保存、处理争议或保护他人权益所必需的信息，可能无法立即删除；我们会在适用规则允许的范围内说明原因。

## 7. 未成年人

本站不以收集未成年人个人信息为目的。未成年人应在监护人指导下访问网站并通过外部平台提交信息；监护人如认为未成年人向维护团队提供了不必要的个人信息，可通过上述邮箱联系我们，以便核实和处理。

## 8. 政策更新与联系方式

如果网站增加账户、表单、统计、广告、支付或其他会显著改变信息处理方式的功能，我们会在上线前或上线时更新本政策，并在必要时提供额外说明。

有关隐私的疑问、请求或安全问题，请发送至 [zhangyuheng@lunadeer.cn](mailto:zhangyuheng@lunadeer.cn)。涉及第三方平台的数据，应同时向相应平台提出请求。
