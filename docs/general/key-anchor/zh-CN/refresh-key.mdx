## 先判断需要哪种操作

| 情况 | 建议操作 |
| --- | --- |
| 密钥可能泄露，但权益仍由你使用 | 登录管理页面，自助更换密钥 |
| 需要将付费权益交给他人 | 使用“更换绑定渠道”转让权益 |
| 密钥遗失或无法登录 | 参阅[密钥遗失后的处理](/docs/general/key-anchor/lost-key)，联系管理员人工找回 |

## 密钥更换

如果怀疑 Key 已经泄露，请立即更换。更换的目的是让原 Key 失效，避免他人继续使用你的付费权益。

### 自助更换（推荐）

如果还能登录资源管理页面，请按以下步骤操作：

1. 登录 KeyAnchor，进入对应资源的管理页面。
2. 在右下角找到“更换 Key”按钮。
3. 点击按钮，按页面提示完成更换。

更换完成后，原 Key 会立即失效，新的 Key 会显示在页面上。请立即复制并妥善保存新 Key，不要再次泄露。

自助更换目前不限制次数。发现泄露后请立即更换，不要等待人工处理。

### 人工协助

如果无法登录，或页面无法完成更换，请通过 QQ 联系管理员：2751268851。为便于核验，请准备以下信息：

- 购买凭证，例如订单号或支付截图；
- Key 绑定的联系方式，例如 QQ 号或邮箱；
- 购买的资源名称。

管理员核实并确认购买信息后，会为你重新发放 Key，原 Key 将被立即吊销。无法确认购买关系时，可能无法完成人工处理。

每个付费权益原则上只提供一次人工更换服务；因再次泄露造成的损失，原则上不再提供人工更换。

## 转让付费权益

是否支持转让，以商品页面和[使用条款](/docs/general/legal/terms)为准。如果允许转让，请按以下步骤操作：

1. 登录 KeyAnchor，进入对应资源的管理页面。
2. 在右下角找到“更换绑定渠道”按钮。
3. 按页面提示重新绑定受益人。

转让完成后，原持有者不再享有以下权益，详情请参阅[使用条款](/docs/general/legal/terms)：

- 付费权益的使用权；
- 付费权益的更新通知；
- 付费权益的售后支持；
- 退款权。

如果你是新的受益人，请在转让完成后登录管理页面并更换一次 Key，以确保只有你持有有效密钥。

> 注意：权益转让是受益人变更，不是复制一份授权。请确认受益人的联系方式无误后再提交。
