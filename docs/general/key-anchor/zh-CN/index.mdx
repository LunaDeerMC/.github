## KeyAnchor 是什么

[KeyAnchor](https://keyanchor.lunadeer.cn/) 是 LunaDeerMC 用于交付付费资源、管理授权权益和提供售后支持的平台。

购买完成后，通常需要使用授权 Key 登录平台。登录后可以查看已购买的资源、下载版本、查看更新日志，并通过工单联系管理员。

## 你可以在这里完成什么

- 激活付费授权，提取并下载资源；
- 查看最新版本、更新日志，以及页面提供的历史版本；
- 绑定 QQ 或邮箱，接收资源更新和工单通知；
- 提交工单，查看处理进度并获得一对一支持；
- 在商品规则和[使用条款](/docs/general/legal/terms)允许的范围内，更换密钥或转让权益。

## 推荐阅读

1. [激活授权与获取资源](/docs/general/key-anchor/obtain)：首次登录、绑定验证渠道和下载资源。
2. [工单与一对一售后](/docs/general/key-anchor/ticket)：遇到安装、配置或使用问题时联系管理员。
3. [更换密钥与转让权益](/docs/general/key-anchor/refresh-key)：密钥泄露、更换密钥或转让付费权益。
4. [密钥遗失后的处理](/docs/general/key-anchor/lost-key)：无法找到授权 Key 时的人工找回流程。

## 使用前须知

授权 Key 是访问付费权益的凭证，请像保管密码一样保管。不要把 Key 发给他人，也不要发布在群聊、工单、截图或公开仓库中。

如果怀疑 Key 已经泄露，请立即[更换密钥](/docs/general/key-anchor/refresh-key)。如果 Key 已经遗失，请参阅[密钥遗失后的处理](/docs/general/key-anchor/lost-key)。
