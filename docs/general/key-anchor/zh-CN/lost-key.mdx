如果找不到授权 Key，通常需要通过人工核验重新发放一枚新 Key。请先根据实际情况选择处理方式：

| 情况 | 处理方式 |
| --- | --- |
| Key 遗失，无法登录平台 | 联系管理员人工找回 |
| Key 仍在手中，但可能已经泄露 | 登录后立即[自助更换密钥](/docs/general/key-anchor/refresh-key) |
| 想把权益交给其他人 | 参阅[更换密钥与转让权益](/docs/general/key-anchor/refresh-key) |

## 人工找回

通过 QQ 联系管理员：2751268851，并提供以下信息以便核验：

- 购买凭证，例如订单号或支付截图；
- 原 Key 绑定的联系方式，例如 QQ 号或邮箱；
- 购买的资源名称。

管理员核实并确认购买信息后，会重新发放一枚新的 Key，原遗失 Key 将被立即吊销。无法确认购买关系时，可能无法完成找回。

## 服务限制

同一个付费权益原则上只提供一次遗失重发服务。再次遗失时，原则上不再提供人工重发。

收到新 Key 后，请立即复制并妥善保存。不要在公开群聊、工单、截图或公开仓库中发送完整 Key。

> 隐私提示：支付截图和日志中可能包含个人信息，请仅通过管理员要求的私聊渠道提供核验所需内容，并遮挡无关的敏感信息。
