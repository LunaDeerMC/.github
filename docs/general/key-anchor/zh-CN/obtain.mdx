## 准备好授权 Key

购买完成后，通常会收到一串以 KALP 开头的授权 Key。它是登录 KeyAnchor、识别付费授权以及使用相关服务的凭证。

请完整复制并妥善保存 Key。不要把它发布在群聊、工单、截图或公开仓库中。

如果 Key 已经遗失，请参阅[密钥遗失后的处理](/docs/general/key-anchor/lost-key)。

如果怀疑 Key 意外泄露，请立即参阅[更换密钥与转让权益](/docs/general/key-anchor/refresh-key)并完成更换。

## 登录并提取资源

1. 打开 [KeyAnchor 平台](https://keyanchor.lunadeer.cn/)。
2. 将完整的授权 Key 粘贴到输入框中。
3. 点击“提取资源”。

![KeyAnchor 首页：输入授权 Key 并点击“提取资源”](/assets/key-anchor/obtain-1.png)

## 首次绑定验证渠道

首次提取资源时，平台可能要求先绑定 QQ 或邮箱。绑定后，平台可以通过该渠道验证登录，并向你发送资源更新和工单通知。

1. 选择 QQ 或邮箱作为验证渠道。
2. 按页面提示完成验证。
3. 验证成功后返回平台，继续提取资源。

![KeyAnchor 绑定 QQ 或邮箱的验证页面](/assets/key-anchor/obtain-2.png)

如果需要通过 QQ 接收和回复工单，建议绑定 QQ，并在资源管理页面开启“通过 QQ 回复工单”。

## 管理和下载资源

绑定成功或再次登录后，会进入已购买资源的管理页面：

![KeyAnchor 资源管理页面：下载版本、查看更新日志和管理通知](/assets/key-anchor/obtain-3.png)

- 点击右上角的“下载最新版”，获取当前可用的资源版本；
- 点击“更新日志”，查看版本更新内容，并在页面提供时获取历史版本；
- 在右侧“通知设置”中开启更新通知或工单通知；
- 需要售后支持时，进入“我的工单”创建工单，具体流程请参阅[工单与一对一售后](/docs/general/key-anchor/ticket)。

> 提示：请妥善保存 Key。下载资源后，后续更新、通知和售后仍可能需要通过 KeyAnchor 登录。
