## A reliable starting path

Start in the works directory, then open the relevant document set. When asking for help, bring the version, logs, and reproduction steps to the right support channel.

1. Choose a work for your server or development environment.
2. Read the installation and first-configuration docs.
3. Verify compatibility in a small environment.
4. Move the stable configuration to production.
