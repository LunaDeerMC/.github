## 从这里开始

先安装插件。首次启动后修改 `config.yml`。使用[命令、时间格式与权限](./commands)调整个人时间、冻结画面和权限。

## 插件行为

TimeManager 只为当前玩家设置客户端时间，不改变服务器世界时间。其他玩家仍然按照服务器的昼夜循环看到世界。作物、生物、红石、天气和定时任务也不会改变。

TimeManager 适合拍摄建筑、观察不同光照下的场景，或在不影响服务器的情况下冻结自己的画面。它不控制全服时间，也不会为世界设置永久的白天或夜晚。

## 安装与首次启动

1. 停止服务器，并备份世界、`plugins/` 目录和服务端日志。
2. 从 [TimeManager GitHub 仓库](https://github.com/LunaDeerMC/TimeManager) 获取 JAR。若仓库没有预构建文件，请按项目构建配置执行 `mvn clean package`，再从 `target/` 中选择构建产物。
3. 将 JAR 放入服务端的 `plugins/` 目录。目录中只保留一个 TimeManager JAR。
4. 启动服务器，检查控制台中的插件启用成功信息。
5. 首次启用后，插件会生成 `plugins/TimeManager/config.yml`。修改配置后重启服务器。插件没有配置重载命令。
6. 用普通玩家账号执行 `/ptime info` 和 `/ptime set day`，确认只改变该账号看到的时间，再用 `/ptime reset` 清理测试状态。

如果插件没有加载，先检查服务端日志中的 Java、API 和插件依赖错误。不要根据 JAR 文件名判断加载结果。

## 配置文件

TimeManager 的配置文件由源码中的配置类首次启动时生成。默认字段如下：

| 配置键 | 默认值 | 作用 |
| --- | --- | --- |
| `debug` | `false` | 输出调试日志。 |
| `enable-time-command` | `true` | 注册 `/ptime` 命令。关闭后，插件不会注册命令执行器。 |
| `show-welcome-message` | `true` | 玩家加入时显示欢迎消息。 |
| `welcome-message` | `&aTimeManager is enabled! Use &e/ptime help &afor commands.` | 加入提示内容，支持 Bukkit `&` 颜色代码。 |

加入事件检查 `timeessence.use` 权限。`plugin.yml` 只声明了 `ptime.set` 和 `ptime.freeze`。因此，即使 `show-welcome-message` 为 `true`，欢迎消息也可能不会显示。请查看日志并执行命令验证插件状态。
