## Who this documentation is for

These docs serve ordinary players who want to use a teleport compass, as well as server owners and administrators who need to install the plugin, tune its settings, and manage permissions. CompassTeleport has a focused feature set, so the set keeps one short introduction index and two practical pages instead of splitting commands, configuration, and troubleshooting into many sections.

## What CompassTeleport is

CompassTeleport uses a vanilla lodestone and compass to create a teleport destination. A player right-clicks a lodestone with a compass, renames the compass in an anvil, and then right-clicks the air while holding the result to return to the lodestone after a short delay. Administrators can change the delay, cooldown, and anvil cost without requiring ordinary players to learn another command.

## Current reference

- CompassTeleport: the repository's current latest release, `v1.4.1`.
- Minecraft API: `1.20`.
- Servers: Spigot, Paper, and Folia servers for which the plugin declares support.
- Build target: the repository's Maven configuration compiles for Java `21`.

Releases and source code may change. When the JAR, generated `config.yml`, or server log differs from this page, prefer the files and logs produced by the current build, and verify the result on a test server.
