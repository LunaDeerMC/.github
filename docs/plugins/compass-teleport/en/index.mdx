## Start here

Use the player page to prepare and use a teleport compass. Use the administrator page to install the plugin, change its settings, and manage permissions.

## Core behavior

CompassTeleport uses a lodestone and a compass to create a teleport destination. Right-click the lodestone with the compass. Rename the compass in an anvil. Hold the result and right-click the air to return to the lodestone after a short delay. Administrators can change the delay, cooldown, and anvil cost.
