## Confirm the version

These docs are based on the current Dominion `4.9.1-release` source, generated configuration, and server behavior, with a live verification on Paper `26.2`. Commands, configuration keys, and UI names may change between releases; when they differ, prefer the files generated by the current plugin and the server log.

## Recommended order

1. Complete [installation](./installation) and confirm that the server has enabled the plugin.
2. Create your first claim with the [claim workflow](./claims), then open access with [permissions and members](./permissions).
3. Read [configuration](./configuration), the [command index](./commands), and [integrations and migration](./integrations) as your server needs them.

Players can open the current UI with `/dominion`; from the console, the same command prints help.

## Scope

- Minecraft `1.20.1–1.20.6`, `1.21.x`, and `26.1.2–26.2` on Bukkit, Spigot, Paper, and Folia.
- Claims, sub-claims, members, groups, permission templates, and environment rules.
- SQLite, MySQL, MariaDB, and PostgreSQL, plus optional Vault, PlaceholderAPI, and WorldGuard integrations.
- Backups before migration, database export/import, and sponsorship information.

All screenshots were freshly captured from a live Dominion 4.9.1-release session on the current 26.2 client; no legacy project screenshots are reused.
