## Support Dominion's long-term maintenance

Dominion is a long-maintained open-source project. Users who would like to support it can visit the [sponsorship page](https://ifdian.net/item/3ce530688c3411f192975254001e7c00). Sponsors receive:

- priority technical support and answers to questions;
- priority evaluation of feature suggestions and improvement requests;
- priority follow-up for bug fixes and optimization suggestions.

## Sponsorship scope

The project balances stability, compatibility, and design for every feature. Sponsorship does not purchase custom development or change the release plan. The project plan decides which requests enter an official release. Implementation is not guaranteed.

When reporting an issue or suggesting an improvement, include the server details, complete log, reproduction steps, and relevant configuration snippets. Do not upload databases or configuration files that contain passwords.
