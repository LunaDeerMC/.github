## Support Dominion's long-term maintenance

Dominion is a long-maintained open-source project. Users who would like to support it can visit the [sponsorship page](https://ifdian.net/item/3ce530688c3411f192975254001e7c00). Sponsors receive:

- priority technical support and answers to questions;
- priority evaluation of feature suggestions and improvement requests;
- priority follow-up for bug fixes and optimization suggestions.

## What sponsorship does and does not promise

Every feature must balance stability, compatibility, and the overall design. Sponsorship is not a purchase of custom development and does not change the project's release planning. Whether a request enters an official release is decided by the project plan; implementation is not guaranteed.

When reporting an issue or suggesting an improvement, include the Dominion version, Minecraft/server-core version, complete log, reproduction steps, and relevant configuration snippets. Do not upload databases or configuration files containing passwords.
