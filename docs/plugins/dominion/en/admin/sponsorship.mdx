## Sponsor benefits

As a sponsor, you will receive:

- Priority technical support and answers to questions;
- Priority evaluation of feature suggestions and improvement requests;
- Priority follow-up for bug fixes and optimization suggestions.

## Implementation boundaries

Dominion is a long-maintained open-source project. Every feature needs to balance stability, compatibility, and overall design. The project plan decides which features enter an official release. The project does not promise to implement every request.

Sponsorship raises the processing priority of feedback, but does not include custom development, nor does it change the project plan. When submitting an issue, include runtime environment information, logs, configuration snippets, and reproduction steps. This information helps the maintainer judge the problem.
