## Optional dependencies

Vault, PlaceholderAPI, and WorldGuard are optional. Dominion's core claim features can run without them.

## Download and install

1. Download a release from the [acquisition section on the work page](/works/dominion) or Dominion's [GitHub Releases](https://github.com/LunaDeerMC/Dominion/releases). Hangar, Modrinth, and Spigot also publish releases.
2. Put the plugin JAR in the server's `plugins/` directory. A release may provide `lite` and `full` variants. Put only one variant in the folder.
3. Start or restart the server. Confirm that the console reports a database connection and `Plugin Enabled!`.
4. Run `/dominion help` in game. `/dominion` should open the UI for a player and print help from the console.

```text
/dominion help
/dominion
```

## Files created on first start

The first start creates or updates files under `plugins/Dominion/`:

- `config.yml` for the database, UI, selection tools, and global behavior;
- `flags.yml` for the current environment and privilege flags;
- `limitations/default.yml` for default claim limits;
- `world-wide/default.yml` for world-wide rules;
- `languages/` for language and UI text;
- `dominion.db` when the default SQLite database is used.

Back up these files and the world before editing them. For an upgrade, replace the plugin JAR without deleting `dominion.db` or overwriting the existing database with an empty one.

If the server does not start, keep the full log and server details before opening an issue on [GitHub Issues](https://github.com/LunaDeerMC/Dominion/issues).
