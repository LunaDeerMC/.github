## EasierBuilding 是什么

EasierBuilding 是一款面向 Paper 与 Folia 服务器、为生存模式设计的建筑辅助插件。它把「想法」到「落地」之间最繁琐的部分交给插件：在世界中选取几个关键点，查看实时预览，确认方案后由插件自动完成放置或拆除。

它不是凭空生成方块的作弊工具，而是真实消耗背包材料与工具耐久、尊重领地保护规则的「建筑助力」。基础功能完全免费，专业能力按需解锁。

## 核心工作流

所有建筑操作都遵循同一个三步流程：

1. **选择**：用准星点击关键位置，确定线条、墙面、立方体或复杂形状的范围；
2. **预览**：在真正消耗材料之前查看半透明的幻影效果，随时调整点位、形态和替换策略；
3. **确认**：确认后由智能队列分帧执行放置或拆除，进度实时反馈，材料不足时自动暂停。

右键开始放置选点，左键开始拆除选点；退出编辑模式后，选点和预览全部清除。

## 重要的边界

- EasierBuilding **没有撤销功能**。建造和拆除一旦提交执行就无法回滚，执行大范围操作前请务必确认预览效果。
- 破坏操作默认**保护矿石与方块实体**（箱子、熔炉等），且受工具亲和性限制，徒手几乎无法拆除，这是防止误伤的刻意设计，不是 Bug。
- 任务材料不足时会**自动暂停**而不是失败，补充材料后到任务菜单手动继续；每个玩家最多同时挂起 3 个暂停任务。
- 受领地保护插件拦截的方块会被**安全跳过**并提示，不会强行破坏玩家财产。
- 专业版功能在基础版中显示为「未解锁」，这是版本差异，不是权限配置错误。
