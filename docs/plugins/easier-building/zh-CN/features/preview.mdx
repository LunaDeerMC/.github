## 所见即所得

EasierBuilding 的核心体验是**实时幻影预览**：选点时，插件会把即将放置 / 拆除的效果以半透明的虚拟方块渲染在你眼前，随准星移动动态更新。确认无误再提交，绝不浪费一块方块。

## 预览长什么样

| 操作 | 预览样式 |
| :--- | :--- |
| 放置 | 真实材质的**半透明幽灵方块**（缩放 0.5） |
| 拆除 | **红色染色玻璃**标记（缩放 1.04） |

- 圆柱模式会额外显示一根**红色混凝土细柱**作为圆心辅助指示物（切换圆心对齐时随之更新，详见[方块中心与方块顶点对齐](../editor/alignment)）；
- 镜像设置完成后会显示一块**蓝色染色玻璃薄板**表示镜像面；
- 任务执行时，处理过的方块会从预览中**逐个移除**，进度一目了然。

## 技术实现

预览使用**客户端专属的虚拟方块实体**（BlockDisplay），只向玩家发送数据包，**不会在世界中创建真实实体**，也不会留下任何痕迹。由版本适配器驱动，支持 1.20.1 / 1.21.11 / 26.1.2 等版本；不支持的服务端版本会提示「预览不可用」并跳过预览（不影响实际执行）。

## 预览上限与降级

单个玩家的预览实体数有上限，超限时会自动降级，避免客户端卡顿：

| 上限 | 默认值 | 行为 |
| :--- | :---: | :--- |
| 软上限 | 2048 | 超过后降低预览质量 |
| 硬上限 | 4096 | 超过后裁剪或拒绝预览 |

超限时的处理方式由 `too-large-mode` 决定：

| 模式 | 行为 |
| :--- | :--- |
| `BORDER_ONLY`（默认） | 只显示选区轮廓 |
| `SAMPLE` | 均匀抽样显示部分方块 |
| `DENY` | 拒绝生成预览 |

降级时会出现「选区过大，已切换为边框预览」之类的字幕提示。预览降级**不影响任务的真实执行**。

## BossBar

编辑模式下，屏幕顶部的 BossBar 分段显示：

| 段 | 含义 |
| :--- | :--- |
| `建造模式：<模式>` | 当前模式名称 |
| `修改器：<修改器>` | 已激活的修改器 |
| 随机：ON | 随机材质袋已作为材料源 |
| 状态：⯈ | 放置任务运行中（整条变绿） |
| 状态：❚❚ | 任务因材料不足暂停（整条变黄） |

启用公平用量时，还会追加两条额度 BossBar（短窗蓝色、周期紫色），详见[公平用量](./fair-usage)。

## ActionBar

屏幕下方的 ActionBar 会一步步引导你：

- 待命状态：提示「左键选择第一个点进入破坏操作选点，手持方块右键选择第一个点进入放置选点」；
- 选点中：绿色（放置）/ 红色（拆除）提示当前该选哪个点（如「继续右键选择中心点（1/3）」），并实时显示**线长、半径、宽高**等参数；
- 任务运行：实时汇报「正在处理：成功 / 跳过 / 失败」；
- 任务暂停：提示暂停原因。

## 什么时候刷新预览

选点、切换手持物品、切换模式 / 变体、按 F 切换对齐、切换世界、切换游戏模式、任务处理进度都会触发预览刷新。刷新频率受 `update-interval-ticks`（默认 5 tick）节流，保证流畅。

## 常见问题

**预览方块会阻挡我吗？会不会被其他玩家看到？**

不会。预览是客户端专属的虚拟实体，只有你自己能看到，不参与碰撞，也不影响其他玩家。

**预览和实际结果会不一致吗？**

替换策略、保护插件拦截、材料不足都会影响最终结果；预览显示的是「预期效果」，被跳过或暂停的方块会在任务报告中如实体现。

**预览太卡怎么办？**

请管理员适当降低 `max-displays-per-player`，或把 `too-large-mode` 调整为 `BORDER_ONLY`（默认）以减少渲染量。
