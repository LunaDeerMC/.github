## 功能是什么

建造任务会**真实消耗背包中的方块**。开启「消耗潜影盒方块」后，当普通背包存储槽中的材料不足时，插件会自动**从你背包内的潜影盒**中继续消耗同类方块，不用频繁往返仓库翻找材料。

> 该功能是**个人设置**，默认关闭，需要每位玩家自己在菜单中打开。

## 如何开启

1. 打开 `/eb` → **个人设置**；
2. 点击「消耗潜影盒方块」按钮，将状态切换为 **ON**；
3. 设置自动保存，下次上线依然生效。

## 消耗顺序

任务消耗材料时按以下顺序取用：

1. **背包存储槽**中的同类方块（优先）；
2. 开启本功能后，背包存储槽不足时，**从背包内的潜影盒**中继续消耗。

同一个任务中两种来源会一起计入材料校验：背包 + 潜影盒里的总数足够，任务就不会因材料不足而暂停。

## 使用前提与限制

- 潜影盒必须**放在你的背包里**（任意存储槽位），插件不会读取世界中的潜影盒；
- 会从**任意一个**背包内的潜影盒中取材料，会真实改动潜影盒内的物品与数量；
- 只适用于**生存模式**的消耗路径；创造 / 旁观模式以及拥有 `easierbuilding.bypass.survival-cost` 权限的玩家本身不消耗材料，不受此设置影响；
- 材料仍会优先消耗背包中的散装方块，本功能只是「补充来源」，不会先掏潜影盒。

## 与随机材质袋的配合

如果你同时开启了[随机材质袋](../editor/randomizer)作为材料源，放置的材质来自袋子，但**消耗的来源**依然是背包与潜影盒 —— 袋子只是决定「放什么」，背包 / 潜影盒决定「从哪里扣」。

## 常见问题

**开启了为什么任务还是暂停提示材料不足？**

先确认材料是否真的足够：本功能只是多一个「从潜影盒扣」的来源，背包 + 潜影盒的总数仍然不足时任务照常暂停。另外确认潜影盒确实在背包里，而不是放在末影箱或世界里。

**会不会把我的潜影盒整个消耗掉？**

不会。插件只从潜影盒内部取出需要的同类方块数量，潜影盒本身（盒子）不会被消耗。
