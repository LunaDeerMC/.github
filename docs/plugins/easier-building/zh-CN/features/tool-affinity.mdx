## 工具亲和性是什么

工具亲和性（Tool Affinity）决定**拆除操作**的速度与资格，还原真实的工具分工：拆石头要用镐、砍木头要用斧、挖土要用铲。它不是惩罚机制，而是防止「徒手秒拆一片山」破坏生存平衡的安全设计。

## 基本规则

- **手持允许的工具**（镐、斧、铲、锄、剪刀等）：按工具基准速度工作；
- **空手或手持非允许物品**：速度为 `bare-hand-speed-multiplier`（默认 **0.0**，即直接跳过该方块，不拆除）；
- 默认情况下**徒手拆除几乎无效** —— 这不是 Bug，而是防误伤的设计。

## 速度怎么算

**基准**：`blocks-per-tick-per-player`（默认每玩家每刻 2 个方块）是无附魔工具的速度基准。

**效率附魔倍率**（默认配置）：

| 效率等级 | 倍率 |
| :---: | :---: |
| 1 | 1.25 |
| 2 | 1.50 |
| 3 | 1.75 |
| 4 | 2.00 |
| 5 | 2.25 |

多个速度类附魔的倍率会**相乘**；实际等级高于最高配置等级时，使用最高等级的倍率。所以「工具升级 + 效率附魔」能显著加快大范围拆除，让附魔真正变得有价值。

> 速度倍率影响的不仅是拆除节奏，也影响每刻的方块处理量：持有高效工具时，每刻处理的方块更多。

## 允许的工具

默认允许 25 种主手物品：木 / 石 / 铁 / 金 / 钻石 / 下界合金的**镐、斧、铲、锄**各 6 种，外加**剪刀**。管理员可以在配置中增删 `allowed-tool-materials`。

## 拆除保护

即使手持正确工具，以下方块默认**无法被批量拆除**：

| 保护类型 | 默认 | 说明 |
| :--- | :---: | :--- |
| 矿物黑名单 | 开启 | 19 种矿物 / 深板岩矿 / 远古残骸，包括煤、铜、铁、金、红石、绿宝石、青金石、钻石、下界金、下界石英 |
| 方块实体 | 禁止 | 箱子、熔炉等带方块实体的方块默认不可批量破坏 |
| 权限 | 需要 | 玩家必须拥有 `easierbuilding.break`（默认全员）才可批量拆除 |

这些保护可以在 `config.yml` 的 `breaking` 分类中调整，详见[管理员手册：配置文件](/docs/plugins/easier-building/admin/configure)。

## 掉落与经验

- 掉落物品：默认**关闭**（`drop-items: false`），且需要权限 `easierbuilding.break.drops`（默认不授予）；
- 经验掉落：默认**关闭**（`drop-exp: false`）；
- 双重限制从根源上杜绝利用拆解刷取物品。

## 耐久消耗

生存模式下，每个方块拆除消耗主手工具 **1 点耐久**（`consume-tool-durability: true`），效率附魔的耐久减免按原版规则生效。耐久不足时任务会暂停（材料不足提示），修复 / 更换工具后继续。

## 常见问题

**为什么我空手拆除一点反应都没有？**

默认配置下空手倍率为 0，空手拆方块会被直接跳过。请手持对应的镐、斧、铲等工具。

**为什么我用钻石镐拆泥土这么慢？**

工具亲和性只区分「允许的工具」与「非允许的工具」，默认不对材料与方块做匹配。所有允许工具共享同一基准速度，提速主要靠效率附魔。

**管理员可以完全关闭工具亲和性吗？**

可以。把 `breaking.tool-affinity.enable` 设为 `false` 后，所有主手状态都使用基础速度。
