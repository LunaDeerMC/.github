## 结构操作是什么

EasierBuilding 专业版提供一套独立的**结构操作**工具：在世界中框选一片区域，把它整体**移动**到新位置，或**复制**成剪贴板后随时**粘贴**到别处。与建造模式不同，结构操作不按形状生成方块，而是原样搬运世界里的真实方块。

> **专业版**：结构操作仅在专业版中可用。基础版主菜单中的「结构操作」显示为「未解锁」，点击后提示联系服主购买专业版。

## 入口与菜单

执行 `/eb` 打开主菜单，点击「结构操作」进入操作菜单：

| 按钮 | 功能 |
| :--- | :--- |
| 移动 | 框选区域，拆除原区域后在目标位置重新放置 |
| 复制 | 框选区域并保存为剪贴板，原区域保持不变 |
| 剪贴板 | 查看、粘贴、删除或持久化已保存的结构 |

开始任何结构操作前，插件会先退出你当前的普通编辑模式并清除已有预览。

## 统一流程

所有结构操作都遵循同一条流程：

1. **选点**：移动 / 复制需要**左键**依次点击 3 个点，确定一个长方体区域；
2. **捕获**：插件读取区域内所有非空气方块，保存成结构快照（移动会先记录快照，再进入目标确认）；
3. **确认目标**：**右键**点击目标位置，确认前可以按 **F** 顺时针旋转 90°；
4. **执行**：操作进入与普通建造 / 拆除相同的任务队列，逐帧处理并实时反馈进度。

## 预览

- 选点阶段：区域边界显示为**黄色拉伸玻璃框**，并带一根红色方向箭头；
- 目标阶段：方块数较少时逐个显示半透明幽灵方块，超过 `large-preview-threshold`（默认 2048）时改为一个**绿色拉伸玻璃框**表示整体范围；
- 方向箭头会随旋转同步变化；三种预览材质都可以由管理员在 `config.yml` 中修改。

## 共同边界

- 移动 / 复制选区的**体积上限为 100 万格**，超过后捕获会被拒绝；
- 提交到队列的放置方块数超过 `max-blocks-per-operation`（默认 10000）时会被拒绝；
- 结构任务与普通任务共用同一队列：每玩家同时运行 1 个任务，材料不足、额度不足、保护拦截、玩家离线、失败过多都会暂停；
- 结构快照只记录方块类型与完整方块状态，**不包含箱子、熔炉等方块实体内的物品与数据**。

管理员可调整的剪贴板数量、持久化与预览参数见[管理员手册：配置文件](/docs/plugins/easier-building/admin/configure)。
