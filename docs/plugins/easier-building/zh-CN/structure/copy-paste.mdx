## 复制

执行 `/eb` → 主菜单「结构操作」→「复制」，然后用**左键**依次点击 3 个点框选区域：

1. **起始角点**；
2. **底面 XZ 对角点**（自动吸附到同一 Y 高度）；
3. **高度点**（只取 Y 高度）。

三个点选完后，插件捕获区域内的非空气方块并提示**在聊天框输入剪贴板名称**：

- 名称不能为空；最长 **128 个字符**，超长部分会被截断；
- 输入的文字会被插件拦截，不会进入公屏；
- 保存成功后自动打开剪贴板菜单，复制过程**不改变源区域、不消耗材料、不消耗公平用量额度**。

> **专业版**：复制和粘贴都需要专业版。

## 剪贴板菜单

「剪贴板」菜单列出你保存的结构，每个条目显示：

- 剪贴板名称；
- 方块数（只统计非空气方块）；
- 体积（选区范围，含空气）；
- 持久化状态。

操作方式：

| 操作 | 效果 |
| :--- | :--- |
| **左键**点击 | 开始粘贴该剪贴板 |
| **右键**点击 | 删除该剪贴板 |
| **Shift 点击** | 切换持久化（内存 ↔ 文件） |

剪贴板默认**只保存在内存中**，退出服务器或重启后失效。Shift 点击切换为持久化后，文件会保存到服务器上的：

```text
plugins/EasierBuilding/clipboards/<玩家UUID>/<剪贴板UUID>.ebclip
```

- `.ebclip` 是插件自有的 gzip NBT 格式，**不是原版结构模板**，请不要手工编辑；
- 持久化剪贴板会在玩家下次上线时自动加载；再按一次 Shift 取消持久化会删除对应文件；
- 每玩家内存剪贴板上限默认为 **10**，其中持久化剪贴板上限默认为 **5**；超过上限时复制或持久化会被拒绝。

## 粘贴

在剪贴板菜单中**左键**点击条目即可开始粘贴：

- **右键**点击目标位置确认；目标位置按当前替换策略解析，与普通放置一致；
- 按 **F** 可将结构**顺时针旋转 90°**（0° / 90° / 180° / 270°）；
- 粘贴会**真实消耗背包材料**，遵守生存模式配置与 `easierbuilding.bypass.survival-cost` 豁免权限；
- 粘贴会应用你当前配置的**修改器**（镜像 / 线性阵列 / 旋转镜像），预览与最终放置使用同一套修改结果；
- 如果修改后的方块数超过 `max-blocks-per-operation`（默认 10000），任务会被拒绝。

## 方块状态与修改器

快照会保留每个方块的**完整方块状态**（例如楼梯朝向、按钮方向）。粘贴时：

- 按 F 的旋转会把方块状态一并旋转 90°；
- 镜像修改器支持 X / Z 轴镜像，对应方向性方块状态会尽力镜像；
- 旋转镜像按 90° 倍率变换方块状态；非 90° 角度会就近吸附到最近的 90° 档位；
- 垂直镜像等 Bukkit 无法精确表示的情况会保留原始方块状态。

## 公平用量

**复制和剪贴板管理不消耗额度**。粘贴进入任务队列后，与普通批量放置一样对**每个尝试处理的方块**扣除 1 点公平用量额度：

- 额度耗尽时任务以「额度不足」暂停，不会失败；
- 额度刷新后可到 `/eb` → 任务菜单继续；
- 结构模式下 BossBar 同样会显示短窗与周期额度条。

完整规则见[公平用量](/docs/plugins/easier-building/features/fair-usage)。

## 注意事项

- 剪贴板只记录方块类型与方块状态，**不保存箱子、熔炉等方块实体内的物品与数据**；
- 粘贴状态下切换世界**不会取消**当前粘贴操作（移动 / 复制选点则会取消）；
- 粘贴结果受替换策略影响：目标位置已有方块时是否被覆盖，取决于你当前选择的替换策略，详见[替换策略](/docs/plugins/easier-building/editor/replace)。
