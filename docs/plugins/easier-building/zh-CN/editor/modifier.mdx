## 修改器是什么

修改器在形状之外叠加**复制变换**：选中一个形状，修改器会自动在别处生成它的镜像、阵列副本。一次选择就能生成整个对称系统，盖对称建筑、环形广场再也不用重复劳动。

> **专业版**：全部修改器都是专业版功能。基础版中显示为「未解锁」。

## 三种修改器

| 修改器 | 用途 | 版本 |
| :--- | :--- | :---: |
| 镜像 | 在世界中定义一面镜子，生成对称的另一半 | 专业版 |
| 线性阵列 | 沿任意方向复制 N 份：一排路灯、一列柱子 | 专业版 |
| 旋转镜像 | 围绕中心旋转复制，生成环形 / 放射状结构 | 专业版 |

修改器可以**同时启用多个**。处理顺序固定为：镜像 → 线性阵列 → 旋转镜像，后一个作用于前一个的输出。最终结果会去重并按坐标排序，避免重复方块。

## 开关与设置

在 `/eb` → 修改器菜单中：

- **Shift 点击**修改器按钮：快速开关；
- **普通点击**：进入对应修改器的设置界面。

启用后，激活的修改器会显示在 BossBar 的「修改器」段中。

## 镜像（Mirror）

镜像需要你**在世界中点 3 个点**来定义镜像面：

1. **镜像面原点**：手持任意物品右键确认。按 **F** 可切换原点对齐方式（方块中心 / 方块顶点，顶点模式会吸附到准星命中的精确坐标），详见[方块中心与方块顶点对齐](/docs/plugins/easier-building/editor/alignment)；
2. **轴线方向**：右键确认镜像面的轴线方向（取视线最接近的 X / Y / Z 轴）；
3. **法线方向**：右键确认镜像面的法线方向（会被限制为与轴线垂直的轴）。

设置完成后，镜像面的预览会以一块**蓝色染色玻璃薄板**显示。之后选点建造时，形状会自动在镜像面的另一侧生成对称副本。

> 设置镜像面时随时可以**左键取消**当前设置，不会保存半成品。

## 线性阵列（Linear Array）

线性阵列沿一个方向复制形状。设置界面中点 3 个点：

1. **参考点**（P1）：形状上的一个基准位置；
2. **第一次复制点**（P2）：确定复制间隔方向与距离（offset = P2 − P1）；
3. **最远复制点**（P3）：确定一共复制多少份（count = 投影长度 ÷ 间隔）。

设置界面会显示当前间隔（offset）与数量（count）。总份数 = count + 1（含原件）。

> **小技巧**：只想保留当前 count 时，第 3 个点点击空气即可确认，无需再找具体方块。
> 修改器设置界面也提供「清除」按钮，随时重置线性阵列。

## 旋转镜像（Radial Mirror）

旋转镜像围绕一个中心点旋转复制形状，适合环形宫殿、放射状广场、风车。设置界面中依次确认：

1. **中心点**：旋转中心（1 个点）；
2. **半径**：中心点 + 边缘一点（2 个点），半径设为 0 表示不限范围；
3. **起始角**：从中心到某一点的方向，作为第一个扇区的起始角度（1 个点）。

**Slices（扇区数）** 在 7 个固定档位中选择：**4 / 6 / 8 / 12 / 16 / 24 / 32**。形状会绕 Y 轴按 360° ÷ slices 逐份旋转复制。

**Alternate（交错）** 开关：开启后奇数扇区会额外镜像，生成更复杂的对称图案。

> 小提示：radius（范围）设 0 时，所有距离的形状都会被复制；设置具体半径时，只复制中心距在范围内的内容。

## 配合使用示例

1. **对称宫殿**：镜像 + 立方体，一次盖出左右完全对称的主殿；
2. **环形广场**：旋转镜像（8 扇区）+ 圆柱，绕中心转一圈全出来；
3. **一排路灯**：线性阵列 + 直线/圆柱，选定方向自动复制 N 根灯柱；
4. **风车 / 轮辐**：旋转镜像（4 或 6 扇区）+ 斜线，放射状骨架瞬间完成。

## 注意事项

- 修改器是**放置与拆除通用的**：拆除操作同样会应用镜像与阵列；
- 启用多个修改器时注意生成数量成倍增长，接近单次操作 10000 方块上限时提交会被拒绝；
- 线性阵列的权限节点在默认配置中需要管理员额外授予，详见[管理员手册：权限节点](/docs/plugins/easier-building/admin/permission)。
