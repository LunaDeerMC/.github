## 两种对齐方式

EasierBuilding 中的部分功能（圆柱的圆心、镜像面的原点）需要一个「基准位置」。这个基准落在**方块中心**还是**方块顶点**，由对齐方式决定：

| 对齐方式 | 基准位置 | 说明 |
| :--- | :--- | :--- |
| 方块中心（BLOCK_CENTER） | 方块的正中心 | 默认方式。点选落在一个方块上时，以该方块中心为基准 |
| 方块顶点（BLOCK_VERTEX） | 方块的角点 | 以方块顶点为基准，适合与方块网格严格对齐的建筑 |

下图从左到右分别展示方块中心对齐与方块顶点对齐：红点是最终吸附的基准位置，背景网格表示方块边界。

## 按 F 键切换

**F 键**（原版「交换副手」键）在编辑过程中被插件捕获，用来切换对齐方式，不会真的交换副手物品。切换会实时刷新预览，并提示当前的对齐方式。

> 仅在你处于编辑模式（或镜像面点选阶段）时按 F 才生效；其他时候 F 键仍然执行原版的交换副手。

## 各功能的对齐行为

### 圆柱：切换圆心对齐

- 在圆柱模式编辑中按 **F**，可在「方块中心」与「方块顶点」间切换**圆心对齐**；
- **切换后会清空当前已选的圆心点**，需要重新选点；
- 方块中心：圆心落在方块中心，圆向外扩展，边缘落在半格上；
- 方块顶点：圆心落在方块顶点，圆与方块网格严格对齐，适合盖严丝合缝的圆塔、烟囱。

### 镜像：切换镜像面原点对齐

- 在设置镜像面的**第 1 步（确认原点）** 时按 **F**，可切换**镜像面原点对齐**；
- 方块中心：原点吸附到点击位置相邻的方块中心；
- 方块顶点：原点吸附到准星命中的**精确坐标**（可做到亚方块精度）；
- 注意：点选进行中（已经确认过轴或法线）按 F 只刷新预览，不会切换；需要先完成或取消当前设置。

## 什么时候用哪种

| 场景 | 推荐 |
| :--- | :--- |
| 盖圆形塔楼、烟囱、立柱 | 方块中心（默认） |
| 圆要与建筑网格、道路严格对齐 | 方块顶点 |
| 镜像面要精确穿过某个坐标 | 方块顶点（吸附精确坐标） |
| 镜像面大致对称即可 | 方块中心（默认） |
