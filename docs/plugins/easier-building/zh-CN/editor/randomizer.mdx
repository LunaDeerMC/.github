## 随机材质袋是什么

想铺出自然风的地面、随机点缀的星空墙面？**随机材质袋（Randomizer Bag）**是一个随机材质配置：登记多种方块类型并设置权重，建造时每个位置按配置随机确定材质，再从背包中消耗对应的方块 —— 铺出来的不是一块块重复的砖，而是一片自然生动的景观。随机材质袋本身不是材料库存，也不会提供建造材料。

> **专业版**：随机材质袋是专业版功能。基础版中显示为「未解锁」。

## 使用步骤

### 1. 配置材质类型与权重

打开 `/eb` → 随机材料袋，把想参与随机的方块物品放入配置槽位（非方块物品会被拒绝并提示）。袋子默认 **27 格**，容量支持 5 或 9 的倍数（最多 54 格）。这些槽位只记录材质类型和权重，不是建造材料库存；实际建造所需的方块仍需准备在背包中。

### 2. 切换为材料源

有两种方式开启「随机材料源」：

- 在主菜单中**Shift 点击**「随机材料袋」按钮；
- 在随机材料袋界面点击保存 / 切换按钮。

开启后，所有**放置**操作都会使用随机材质袋中的配置替代主手方块：每个位置按配置随机确定放置材质，成功放置时从背包中消耗对应的方块。若开启了潜影盒消耗设置，也会从背包内的潜影盒中继续消耗。此时 BossBar 会显示「随机：ON」。

### 3. 开始建造

正常进入编辑模式选点建造即可。每个位置的材质按**确定性随机**抽取（见下），重复建造同样的形状会得到同样的材质分布。

> 拆除操作始终使用红色标记预览，不受随机材质袋影响。

## 权重：数量即概率

随机材质袋**支持权重**：想提高某种材质的出现比例，就在配置中为它占用更多槽位 —— 每个槽位独立计数，材质出现的概率等于它在配置中的**槽位数量占比**。

例如配置 **两个泥土槽位 + 一个沙子槽位**：

| 配置槽位内容 | 每个位置的概率 |
| :--- | :--- |
| 泥土 ×2 | 2/3（约 67%） |
| 沙子 ×1 | 1/3（约 33%） |

比例正好是 **2 : 1**。想要 1 : 1 的均匀分布，就为泥土和沙子配置相同数量的槽位；想偏重某一种，多占用几个槽位即可，无需任何额外配置。

> 一个槽位只能配置一个方块物品，重复配置请使用多个槽位（例如把两个泥土分别放在两个不同的槽位）。「清空」按钮会移除袋中的材质配置。

## 随机规则：完全确定

随机取材不是「每次都不一样」的真随机：

- 种子由**模式、操作类型、选点坐标**共同决定；
- 改变选点（形状、位置）会得到不同的材质分布；
- **同样的选点 + 同样的材质配置，永远得到同样的结果** —— 你可以放心预览确认，重做也不怕「开出不同的花」。

## 使用场景

| 场景 | 推荐材质配置 | 配比思路 |
| :--- | :--- | :--- |
| 自然地面 | 草方块、泥土、砂砾、石头、苔藓块 | 草方块 ×3、泥土 ×2，其余 ×1，草多土少的自然感 |
| 星空 / 装饰墙面 | 各种染色玻璃、荧石、紫珀块 | 底色玻璃多放，荧石点缀放 1–2 个 |
| 碎石路 | 圆石、苔石、石头、砂砾 | 圆石 ×2、砂砾 ×2 做底，苔石少量点缀 |
| 生态过渡带 | 沙子、红沙、沙砾、砂岩 | 主沙 ×3、过渡沙 ×2、其余 ×1，形成渐变密度 |

## 注意事项

- 随机材质袋不会提供材料；成功放置时会真实消耗背包中**与所选材质对应的方块**，若开启潜影盒消耗设置，也会从背包内的潜影盒中继续消耗；
- 材质配置为空时无法作为材料源，会提示先配置方块；
- 背包材料不足时任务会照常自动暂停，补齐后再继续；
- 材质槽位数量由配置容量决定（默认 27 格），重复配置同种材质会占多个槽位，注意为其他材质留出空间。
