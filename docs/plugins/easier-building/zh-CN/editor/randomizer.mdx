## 随机材质袋是什么

想铺出自然风的地面、随机点缀的星空墙面？把多种方块放进**随机材质袋（Randomizer Bag）**，建造时每个位置自动从袋中随机抽取材质 —— 铺出来的不是一块块重复的砖，而是一片自然生动的景观。

> **专业版**：随机材质袋是专业版功能。基础版中显示为「未解锁」。

## 使用步骤

### 1. 放入材质

打开 `/eb` → 随机材料袋，把想要的方块物品放入袋中（非方块物品会被拒绝并提示）。袋子默认 **27 格**，容量支持 5 或 9 的倍数（最多 54 格）。

### 2. 切换为材料源

有两种方式开启「随机材料源」：

- 在主菜单中**Shift 点击**「随机材料袋」按钮；
- 在随机材料袋界面点击保存 / 切换按钮。

开启后，所有**放置**操作都会从袋子中取材，替代主手方块。此时 BossBar 会显示「随机：ON」。

### 3. 开始建造

正常进入编辑模式选点建造即可。每个位置的材质按**确定性随机**抽取（见下），重复建造同样的形状会得到同样的材质分布。

> 拆除操作始终使用红色标记预览，不受随机材质袋影响。

## 权重：数量即概率

随机材质袋**支持权重**：想提高某种材质的出现比例，就往袋子里多放几个它 —— 每个槽位独立计数，材质出现的概率等于它在袋子中的**数量占比**。

例如放入 **两个泥土 + 一个沙子**：

| 袋子内容 | 每个位置的概率 |
| :--- | :--- |
| 泥土 ×2 | 2/3（约 67%） |
| 沙子 ×1 | 1/3（约 33%） |

比例正好是 **2 : 1**。想要 1 : 1 的均匀分布，就放相同数量的泥土和沙子；想偏重某一种，多放几个即可，无需任何额外配置。

> 一个槽位只能放一个方块物品，重复放入请使用多个槽位（例如把两个泥土分别放在两个不同的槽位）。「清空」按钮会移除袋中所有材质。

## 随机规则：完全确定

随机取材不是「每次都不一样」的真随机：

- 种子由**模式、操作类型、选点坐标**共同决定；
- 改变选点（形状、位置）会得到不同的材质分布；
- **同样的选点 + 同样的袋子内容，永远得到同样的结果** —— 你可以放心预览确认，重做也不怕「开出不同的花」。

## 使用场景

| 场景 | 推荐袋内材质 | 配比思路 |
| :--- | :--- | :--- |
| 自然地面 | 草方块、泥土、砂砾、石头、苔藓块 | 草方块 ×3、泥土 ×2，其余 ×1，草多土少的自然感 |
| 星空 / 装饰墙面 | 各种染色玻璃、荧石、紫珀块 | 底色玻璃多放，荧石点缀放 1–2 个 |
| 碎石路 | 圆石、苔石、石头、砂砾 | 圆石 ×2、砂砾 ×2 做底，苔石少量点缀 |
| 生态过渡带 | 沙子、红沙、沙砾、砂岩 | 主沙 ×3、过渡沙 ×2、其余 ×1，形成渐变密度 |

## 注意事项

- 随机材质袋会真实消耗背包中**对应材质的方块**，袋子只是决定放什么，不会凭空生成材料；
- 袋子为空时无法作为材料源，会提示先放入方块；
- 背包材料不足时任务会照常自动暂停，补齐后再继续；
- 材质槽位数量由袋子容量决定（默认 27 格），重复放入同种材质会占多个槽位，注意为其他材质留出空间。
