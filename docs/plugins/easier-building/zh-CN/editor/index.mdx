## 编辑模式是什么

打开 `/eb` 主菜单，点击「建造模式」即可进入编辑模式。编辑模式由几层可叠加的能力组成：

1. **建造模式**：决定生成什么形状（直线、墙面、立方体、球体……）；
2. **模式变体**：决定形状的形态（实心、空心、边框、仅表面……）；
3. **替换策略**：决定放置时替换哪些方块（仅空气、副手匹配、白名单……）；
4. **修改器**：在形状之外叠加复制变换（镜像、线性阵列、旋转镜像）；
5. **随机材料**：使用随机材质袋中的材质类型与权重配置，放置时从背包消耗对应材料，铺出自然景观。

这些设置会保存在你的玩家档案中，下次上线自动还原。选点完成后任务进入队列分帧执行，详见[任务与队列](./task)。

## 选点操作基础

- **右键**点击方块 = 开始**放置**选点；**左键**点击方块 = 开始**拆除**选点；
- 选点过程中按自己的节奏逐个确认，最后一个点选完即自动提交；
- 选点中误点导致方向错误时，**再点击一次**可退出当前操作，不会提交；
- 切换世界会清空选点；退出编辑模式会清除选点和预览；
- 放置操作会真实消耗背包材料，拆除操作会消耗工具耐久，请提前备足。

## 编辑模式注意事项

- 每个玩家同一时间只能运行 **1 个任务**；暂停任务上限 **3 个**；
- 单次操作最多 **10000 个方块**，超出会在提交时被拒绝；
- 预览过大的选区会降级显示（详见[实时预览与 HUD](../features/preview)），不影响执行。
