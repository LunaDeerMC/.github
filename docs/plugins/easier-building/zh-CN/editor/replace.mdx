## 替换策略是什么

放置操作执行时，目标位置可能已有方块。**替换策略**决定这些位置能不能被替换、替换成什么。在 `/eb` → 替换策略菜单中切换，当前策略会显示在菜单左上角。

## 五种策略

| 策略 | 行为 | 版本 | 默认权限 |
| :--- | :--- | :---: | :---: |
| 仅空气 | 只替换空气与可替换方块（水、岩浆、草、高草丛、蕨、藤蔓、雪等） | 免费 | 默认开启 |
| 空气与方块 | 替换一切（空气和方块都替换） | 专业版 | 默认关闭 |
| 仅方块 | 只替换非空气的已有方块 | 专业版 | 默认关闭 |
| 副手匹配 | 只替换与副手物品同材质的方块 | 专业版 | 默认关闭 |
| 白名单 | 只替换玩家自定义白名单内的方块 | 专业版 | 默认关闭 |

### 仅空气（免费，默认）

最安全的策略。只在空气（及水、草等可替换方块）位置放置，**绝不覆盖已有建筑**。新手和日常建造的默认选择，误伤概率最低。

### 空气与方块（专业版）

大范围重铺地面、翻新墙体的主力策略。会覆盖目标范围内的所有方块，包括已有建筑。执行前务必确认预览。

### 仅方块（专业版）

只替换已有方块的位置，空气位置保持不动。适合在已有结构上精确替换材料，例如把一面石墙整体换成砖墙。

### 副手匹配（专业版）

副手（左手）拿什么方块，就只替换与它同材质的方块。适合「只换木头部分、保留石头部分」这类按材质筛选的操作。

### 白名单（专业版）

只替换白名单内的方块。白名单通过 GUI 编辑器维护：放入方块物品保存，被列入的方块才会被替换。

## 快捷替换

替换策略菜单中还有一个 **快速替换** 开关（专业版）：

- 开启后，**右键**选点时直接选中**被点击的那个方块本身**（而不是相邻的空气位置）；
- 适合在已有墙体上直接框选并替换目标方块，配合「仅方块」或「白名单」策略使用效果最佳。

## 维护替换白名单

1. 打开 `/eb` → 替换策略 → 「编辑替换白名单」；
2. 把想允许替换的方块物品放进界面（非方块物品会被拒绝）；
3. 点击「保存」；点击「清空」移除全部白名单方块；
4. 切到「白名单」策略即可生效。

## 选择建议

| 场景 | 推荐策略 |
| :--- | :--- |
| 新盖一面墙、填一个房间 | 仅空气 |
| 整片重铺地面、翻新墙面 | 空气与方块 |
| 只替换已有方块的材料 | 仅方块 |
| 按材质局部替换（只动木头 / 只动石头） | 副手匹配 |
| 精细控制可替换的种类 | 白名单 |

> 提示：替换策略只影响**放置**操作；拆除操作不受替换策略影响。
