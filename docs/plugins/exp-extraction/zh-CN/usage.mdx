## 快速使用

1. 确认服务器已经安装并启用 ExpExtraction。
2. 使用 `/extract 100` 提取 100 点经验，或者直接使用 `/extract` 让插件按当前经验计算提取数量。
3. 在玩家附近拾取生成的经验瓶。
4. 手持经验瓶右键，将瓶内经验返还给自己。

如果你想使用附魔台路径，请准备空玻璃瓶，潜行后手持它右键附魔台。

## 使用命令提取

```text
/extract [amount]
```

| 参数 | 说明 |
| --- | --- |
| `amount` | 可选的非负整数，表示本次要提取的经验数量 |
| 省略参数 | 使用玩家当前总经验，但最终仍受单瓶最大值限制 |

命令成功后，插件会在玩家所在位置附近生成一个经验瓶，并从玩家总经验中扣除相应数量。当前默认单瓶最多保存 `2000` 点经验；如果请求数量超过这个值，插件会提示并把本次数量限制为 `2000`。

以下情况不会生成经验瓶：参数不是整数、参数为负数、玩家经验不足，或玩家没有可提取的经验。

## 使用附魔台提取

附魔台路径不需要输入数量：

1. 手持至少一个空玻璃瓶。
2. 按住潜行键。
3. 对附魔台右键。

每次成功会消耗一个空玻璃瓶，并生成一个经验瓶。默认每次提取 `100` 点；如果玩家剩余经验不足，实际数量会降低到当前可用经验。

## 使用经验瓶

插件生成的经验瓶仍然使用 Minecraft 的经验瓶物品表现，但其中带有插件写入的经验数量和来源玩家信息。手持它右键时：

- 瓶内经验会直接加入当前玩家的经验；
- 播放升级音效并显示获得的经验数量；
- 当前使用的一个瓶子会被消耗；
- 事件会被插件取消，不会把它当作普通投掷物发射。

普通的原版经验瓶不包含 ExpExtraction 的自定义数据，不会触发这套返还逻辑。

## 权限和常见限制

- `/extract` 需要 `expextraction.extract` 权限；该权限在插件声明中默认给玩家。
- 当前附魔台提取路径没有单独的权限判断，因此撤销 `expextraction.extract` 不会自动禁止附魔台提取。
- 控制台不能使用 `/extract`；这是玩家命令，不是管理员控制台命令。
- 如果命令突然不可用，先确认管理员没有将 `commandExtraction.enable` 设为 `false`，再检查权限和玩家当前经验。
