## 文档范围

ExpExtraction 是一个把经验封存进附魔之瓶的轻量 Minecraft 插件。本文档按仓库 `master` 分支和 `1.3.2` 构建配置整理；插件声明 Minecraft `1.20` API 和 Folia 支持，实际适配仍应以目标服务端测试结果为准。

它没有数据库、面板或复杂的管理系统，管理员只需要完成插件安装、权限分配和两个经验提取路径的配置，玩家就可以使用命令或附魔台保存经验。

## 它能做什么

- `/extract [amount]`：把经验提取为插件生成的经验瓶；省略数量时使用当前总经验，但单瓶仍受命令上限限制。
- 附魔台提取：潜行、手持空玻璃瓶并右键附魔台，按配置提取固定数量的经验。
- 经验瓶使用：手持插件生成的经验瓶右键，直接获得其中的经验并消耗一个瓶子。
- 轻量部署：支持 Paper 与 Folia，不需要额外数据库或运行时依赖。

## 默认值和边界

- 命令提取的单瓶最大值默认为 `2000` 点经验。
- 附魔台提取每次默认为 `100` 点经验；玩家经验不足时会按实际剩余经验提取。
- `/extract` 只允许玩家执行，控制台不能使用这个命令。
- 当前版本的 `enchantingTable.enable` 虽然会出现在配置文件中，但附魔台事件实际检查 `commandExtraction.enable`；管理员应阅读[安装与配置](./installation)中的说明。
