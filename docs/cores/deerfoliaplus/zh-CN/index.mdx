## 使用 DeerFoliaPlus

将 DeerFoliaPlus 作为启动命令中的服务端核心使用。它不是插件。不要把 jar 放入 `plugins/`。

需要使用 Syncmatica、Servux 或 Recipe Sync 的玩家还需要匹配的客户端组件。开启协议前，请先确认客户端兼容性。
