## Use DeerFoliaPlus

Use DeerFoliaPlus as the server core in your startup command. It is not a plugin. Do not put its jar in `plugins/`.

Players who use Syncmatica, Servux, or Recipe Sync also need the matching client components. Check client compatibility before you enable a protocol.
