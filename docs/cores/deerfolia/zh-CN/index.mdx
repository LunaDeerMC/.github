## 使用 DeerFolia

将 DeerFolia 作为启动命令中的服务端核心使用。它不是插件。不要把 jar 放入 `plugins/`，也不要在 Paper 或 Purpur 进程中加载 DeerFolia 配置。

你不需要先阅读 Java 源码或 Paperweight 补丁代码。迁移前，请先确认插件兼容性。

## 迁移前备份

切换服务端核心前，备份以下内容：

- 所有世界目录；
- server.properties、eula.txt、配置目录；
- 插件数据、数据库和定时任务；
- 当前正在使用的服务端 jar 与启动脚本。

先使用生产服务器的副本启动。检查插件加载、玩家登录、传送、区块加载和常用机器。全部检查通过后，再迁移生产服务器。

## 判断 DeerFolia 是否适合

Folia 可以并行运行相互分离的玩家区域。玩家分散在不同区域时，这种方式可能有效。玩家长期集中在一小片区域时，收益可能不明显。

许多 Paper 插件需要明确支持 Folia。迁移前，请逐个查看插件的兼容性说明。

DeerFolia 可能改变高密度实体区域、村民 POI、路径查找和挂机网络同步的更新节奏。先使用默认值。每次修改都在服务器副本中测试。
