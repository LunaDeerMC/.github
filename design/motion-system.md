# 全站动效与首页视差系统

> 本文档定义已确认的首页运动关系与普通页面动效边界。旧版「镜流」、景深恢复和倒影展开方案已废弃。

- 最后更新：2026-08-03
- 状态：首页空间关系已确认；白天／黑夜两套四层资源已完成同母版像素对齐与滚动校准

## 首页动作语言

首页只使用一种主要空间动作：向下滚动时，一个统一的四层 Minecraft 场景产生差速向上位移。

```text
背景／天空       近似静止或最慢
远景             慢速向上
中景             中速向上
近景             最快向上
```

速度关系必须是**远慢近快**。近景更快地进入并占据视口，远景只发生轻微变化，由此形成观察视角逐渐降低的错觉。

所有活动层的方向一致；差别只在位移幅度。动作不是摄影机飞行、场景切换、独立遮罩扫过或各组件逐个表演。

## 参考机制，不是最终参数

Material for MkDocs 的参考实现使用 `perspective: 2.5rem`，并为图层设置 `8 / 5 / 2 / 1` 的深度值。层通过 `translateZ(-perspective × depth)` 进入透视空间，再用 `scale(depth + 1)` 抵消视觉缩放。

在这种透视关系下，屏幕中的近似滚动响应为 `1 / (depth + 1)`：

| 参考 depth | 近似响应 | 体感 |
| --- | --- | --- |
| 8 | `1/9` | 最慢、最远 |
| 5 | `1/6` | 较慢 |
| 2 | `1/3` | 较快 |
| 1 | `1/2` | 最快、最近 |

这组数值只解释参考站点为何呈现“远慢近快”，不能直接视作本站最终参数。正式页面目前使用白天牧场与夜间红石工坊两套重新设计、同母版像素对齐的四个通道：天空层使用完整场景母版，其余三层使用同一母版的颜色像素与独立 alpha 轮廓，并以 sticky 视口承载滚动；首版桌面位移为 `-10 / -42 / -88 / -156px`，移动端为 `-8 / -28 / -58 / -112px`。

## 校准方法

下一轮动效验证应只使用结构正确的临时分层素材，并按以下顺序判断：

1. 先锁定背景与地平线，确认画面没有整体漂移感。
2. 调整近景，使其在目标滚动距离内自然接管视口。
3. 调整中景，使其既能体现空间差，又不与近景脱节。
4. 最后微调远景，确保它可被感知但保持稳定。
5. 用慢速、快速、反向滚动和触控惯性录屏共同验收。

不能用 Hero 文案淡出、渐变遮罩或裁切来掩盖错误的速度关系。

## 首屏内容退场

- Hero 文案在初始停留区间保持稳定。
- 进入滚动后，文案可以在短距离内轻微向上并降低透明度。
- 导航几何结构保持不变，只按背景对比需要改变表面与分隔。
- 向下提示可以使用小幅循环位移，但不得影响内容理解。

文案退场节奏尚未确认，必须在图层速度关系正确后再校准。

## 同色过渡

- 最前景底部、融合层终点与精选作品背景共享同一个颜色令牌。
- 正式色值尚未确定；当前原型的 `#17182E` 只是临时值。
- 过渡不依赖整屏硬遮罩或与场景无关的彩色渐变。

## 普通页面

- 支持、关于、作品列表和文档不复制首页视差。
- 普通进入、悬停和选中反馈保持在约 `110–260ms`。
- 链接箭头可以轻微横移；按钮不做大幅上浮、弹跳或强发光。
- 文档和高频界面不使用持续视差。

## 减少动态

启用 `prefers-reduced-motion: reduce` 时：

- 取消 3D 透视视差和 Hero 滚动退场位移。
- 使用静态合成场景。
- 取消循环向下提示和装饰性箭头位移。
- 精选作品继续按正常文档流显示。

## 防偏离约束

- 不恢复「镜流」、景深模糊、倒影展开或连续摄影机路径。
- 不让远景比近景移动得更快。
- 不用横贯视口的矩形前景或遮罩制造假过渡。
- 不加入全屏粒子、像素分解、巨型月相遮罩或循环呼吸缩放。
- 不让动画阻止滚动、链接点击或键盘操作。

## 验收标准

- 远景慢、近景快，且所有活动层随向下滚动向上移动。
- 速度差表达空间深度，但图层仍保持为一个完整场景；初始位置不能出现天空露底、湖面断裂或建筑重影。
- 快速滚动、反向滚动和触控惯性下无跳变或露底。
- 导航、Hero 文案和作品内容始终可操作。
- 场景与实心内容区的衔接没有色缝或硬边。
- 减少动态后信息顺序与主要入口不改变。
