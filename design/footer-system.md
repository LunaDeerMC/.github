# 全站页脚系统

> 本文档定义 LunaDeerMC 官网全站页脚的内容结构、主题外观与响应式原则。页脚承担品牌收尾和必要辅助入口，不作为第二套站点地图。

- 最后更新：2026-08-02
- 状态：结构、主题与场景过渡已确认

## 总体结论

页脚采用“品牌收尾＋主要链接＋法律底栏”的两层结构，取代传统的多列链接目录：

```text
LunaDeerMC
To the moon, to the dream, to the future!

作品   文档   支持   关于   GitHub

────────────────────────────────────────

© {year} LunaDeerMC        隐私政策   使用条款   法律与政策
```

第一层让页面回到 LunaDeerMC 品牌，并提供少量主要出口；第二层承担版权与必须长期可找到的政策入口。

网站切换为英文时，页脚所有入口、政策名称和辅助语义同步使用英文；Logo、链接顺序和两层结构不改变。页脚本身不重复提供语言切换，语言入口统一位于全站导航功能菜单。

## 内容职责

### 品牌收尾

- 显示 LunaDeerMC Logo 或标准字标。
- 全站统一使用 `design/assets/lunadeermc-brand-logo.png` 原始 Logo 资产；保留原始像素、比例与 Alpha 通道，不反相、不重绘、不改色、不做发光或线稿化处理。深色模式也不生成反白、单色或“全透明”变体；透明区域只显示当前页脚表面。
- 使用 `To the moon, to the dream, to the future!` 作为简短品牌口号。
- 不在页脚重复首页辅助文案、组织介绍或作品宣传内容。

### 主要链接

只保留：

- 作品
- 文档
- 支持
- 关于
- GitHub

作品与文档是内容入口，支持与关于是组织入口，GitHub 是唯一直接放入页脚的核心外部渠道。GitHub 必须带有可访问的外链说明；是否显示外链图标在图标与排版阶段确定。

### 法律底栏

只保留：

- 自动生成的当前年份与 `LunaDeerMC`
- 隐私政策
- 使用条款
- 法律与政策

隐私政策和使用条款可以直接进入“文档 → 通用 → 法律与政策”中的对应页面；“法律与政策”进入支持中心的法律入口，再由那里引导至完整政策文档集。

第三方声明、商标与免责声明、获取与退款不全部平铺在页脚，避免形成密集法律目录。

## 不在页脚出现的内容

- 具体作品、作品分类和归档作品。
- QQ 群号、支持邮箱、购买平台与赞助方式。
- 作品获取按钮、价格、授权档次或兼容性。
- 文档分类和具体文档集。
- 第三方声明、商标免责、获取与退款等完整政策列表。
- 与顶部导航和支持页重复的大量外部链接。

这些信息分别由作品页、文档首页、支持中心和通用文档承担。

## 一套结构，两种外观

页脚保持相同内容、顺序和排版比例，只根据页面职责切换视觉表面。

### 双主题品牌页面

用于首页、支持和关于：

- 页脚根据当前浅色或深色主题自然融入页面末段，不出现突兀的独立大色块。
- 深色继承黄昏红石工坊的暖炭褐关系；浅色继承白天牧场的燕麦与浅石关系。
- 首页中，它应在精选作品、等权文档与支持入口、简短组织介绍之后，通过 Quiet Field 和 Horizon Veil 安静收尾，不恢复旧版水域场景。
- 文字、分隔和外链反馈使用当前主题的语义令牌。
- 不增加庞大插画、霓虹渐变、强玻璃容器或另一段争夺注意力的动态背景。

### 双主题内容页面

用于作品、默认作品介绍页、文档、搜索和其他通用页面：

- 浅色和深色使用相同布局，通过语义设计令牌切换表面、文字和分隔。
- 采用已确认的“地平线薄雾”过渡：页脚顶部可以使用一条浅而宽的场景过渡带，再淡入独立的页脚表面；场景只承担内容收束，不承载页脚文字。
- 场景过渡带使用全宽、低对比度的横向裁切，宽屏参考高度约 120–150px；上下边缘以自然雾化与周围表面连接，不使用硬边框、卡片或厚重阴影。
- 页脚品牌区、主要链接和法律底栏仍落在稳定的表面上，保持方案一的“左侧品牌、右侧单行主要链接、下层法律信息”布局。
- 页脚与正文依靠场景过渡、大留白和低对比度分隔线衔接，不使用厚重色块切断阅读。
- 浅色表面避免刺眼纯白，深色表面避免与正文完全混成一层。
- 页脚不承担主题切换；主题控制仍位于全站导航的功能菜单。

#### 场景与主题配对

- 白天牧场：使用白天牧场场景作为过渡图，适度降低饱和度与对比度；下方页脚表面延续燕麦、浅石和牧草绿关系。
- 黄昏红石工坊：使用黄昏红石场景作为过渡图，进一步压低饱和度与发光细节，避免红石灯光抢占品牌收束；下方页脚表面使用略抬高、偏暖的炭褐，不能与正文混成一整块近黑区域。
- 深色文字与 Logo 使用暖燕麦或柔和象牙色，口号和法律信息使用蘑菇灰褐；红石珊瑚只用于少量状态、激活线或外链反馈，不作为大面积背景或整组图标颜色。
- 场景图不叠加页脚文字，不加入新的作品、渠道、价格、兼容性或主题控制入口。

### 自定义作品页

自定义 `index.astro` 作品页可以让页脚适配作品自身视觉，也可以复用全站页脚。无论选择哪种形式，都需要保留版权、主要全站入口和必要政策访问能力，且不能改写用户保存的全站主题偏好。

## 响应式布局

- 宽屏使用舒展的横向关系：品牌区域占据主要空间，主要链接作为一组轻量文字入口，法律信息位于底部一行。
- 中等宽度（平板参考 834px）采用已确认的“Balanced Midwide”：场景过渡带约 72–88px，页脚保持左右两列，左侧为品牌区，右侧为两列自然链接网格；法律信息回到底部一行。
- 中等宽度的两列关系是开放网格，不使用卡片、按钮背景或等宽模块；空间不足时，主要链接可自然换行，但不改变入口顺序。
- 窄屏采用已确认的“安静页脚账本”：场景过渡带控制在约 44–56px，随后依次纵向排列居中品牌区、带细分隔线的主要链接列表和法律底栏。
- 移动端品牌区使用官方 Logo、LunaDeerMC 字标与口号的居中堆叠；主要链接保持文本列表，不改成按钮或手风琴。
- 移动端主要链接按单列展示，使用舒适行距与足够触控高度；GitHub 保留外链语义图标，其余入口不增加装饰性图标。
- 移动端法律信息允许自然换行，版权信息与三项政策入口仍保持同一法律底栏职责。
- 移动端不使用手风琴或折叠面板；当前链接数量足够少，直接展示更容易扫描。
- 主要链接在窄屏优先保持单列；只有在更宽的窄屏断点出现明显空间余量时，才允许自然换行，不引入等宽按钮组。
- 触控目标需要足够大，但不通过给每个链接增加明显按钮背景实现。

## 视觉与交互原则

- 页脚的存在感来自空间、排版比例和高质量背景衔接，而不是信息数量。
- 场景图片只作为内容到页脚的过渡媒介；它可以自然延续页面氛围，但不能演变成第二个 Hero 或作品宣传区。
- Logo、口号、主要链接和法律信息形成清晰的三层文字层级。
- 普通链接的悬停、焦点和当前状态延续全站导航的克制反馈与可访问性要求。
- 外部链接提供明确语义，不能只依赖图标表达“将在新位置打开”。
- 页脚年份在构建时生成，不在内容文件中手工维护。
- 页面内容较短时，页脚仍位于视口底部或其后，不悬浮覆盖正文。

## 实现阶段校准

- 各断点下场景过渡带的具体裁切焦点。
- Quiet Field 的最终高度与 Horizon Veil 的精确透明度在正式首页内容和生产场景资产中光学校准，不改变已经确认的内容顺序与页脚职责。
