# 全站搜索体验

> 本文档定义 LunaDeerMC 官网快速搜索与完整结果页的内容结构、上下文范围、主题外观和交互方式。搜索索引与构建实现以技术架构文档为准。

- 最后更新：2026-07-23
- 状态：快速搜索结构、响应式形态与主题边界已确认

## 总体结论

全站只维护一套搜索能力：

```text
桌面端
└── 视口上部的命令面板，用于快速搜索和少量最佳结果

窄屏
└── 完整搜索界面，用于输入、范围切换和结果滚动

/search
└── 可分享、可保留查询状态的完整结果页
```

作品、文档、支持内容和其他公开页面使用同一索引与结果模型。文档系统不建立第二套互不相关的搜索。

网站全局支持中文与英文。搜索界面、输入提示、范围名称和结果元数据都必须本地化；缺少翻译的文档不进入目标语言搜索结果。

搜索严格限制在当前语言：

- 中文页面只显示中文页面结果。
- 英文页面只显示英文页面结果。
- 不在单次搜索中混合或合并两种语言。
- 用户需要搜索另一种语言时，先通过全站语言切换进入对应页面。
- 查询文字不自动翻译，也不在语言切换后自动替换成另一语言关键词。

## 入口

- 全站导航功能菜单提供“搜索站内内容”。
- 桌面端支持 `Command/Ctrl + K` 从任何使用全站导航的页面打开。
- 文档首页可以提供更明确的搜索入口，但打开的仍是同一快速搜索界面。
- 打开搜索前关闭导航功能菜单，不能让两层浮层同时存在。
- 关闭搜索后恢复原页面、焦点和滚动位置。

## 桌面端命令面板

面板位于视口上部偏中间，不严格垂直居中：

```text
┌────────────────────────────────────────┐
│  搜索作品与文档……              ⌘ K   │
├────────────────────────────────────────┤
│  当前文档集     全部文档     全站      │
├────────────────────────────────────────┤
│  数据库配置                            │
│  Example Work / 配置                   │
│  设置外部数据库连接与连接池……          │
│                                        │
│  Example Work                          │
│  作品 / 插件                           │
│  用于……                                │
└────────────────────────────────────────┘
```

### 布局

- 输入框是唯一的强视觉焦点。
- 搜索范围使用轻量文字切换，不使用彩色胶囊。
- 结果采用连续单列列表和留白分隔，不将每条结果包成独立卡片。
- 面板只展示少量最佳结果，底部提供“查看全部结果”进入 `/search?q={query}`。
- 面板高度达到上限后只让结果区域滚动，输入框与范围切换保持可见。

### 结果内容

每条结果最多展示：

- 标题
- 所属路径、文档集或内容类型
- 最多两行命中摘要
- 必要的归档状态

不展示封面大图、兼容性列表、价格、下载量、多个彩色标签或其他与定位结果无关的元数据。

当前键盘选中结果使用低对比表面与左侧细标记，不使用高饱和色块。

### 键盘操作

- 打开后焦点直接进入搜索输入框。
- 上下方向键在结果中移动。
- `Enter` 打开当前结果。
- `Escape` 关闭搜索并将焦点交还给原触发入口。
- `Command/Ctrl + K` 在搜索关闭时打开；搜索已经打开时不清空已有输入。
- 焦点不能离开仍然处于打开状态的模态搜索面板。

## 搜索上下文

默认范围根据打开搜索的位置确定：

```text
作品文档阅读页
└── 当前文档集 → 全部文档 → 全站

文档分类页
└── 当前分类 → 全部文档 → 全站

文档首页
└── 全部文档 → 全站

作品页、支持、关于和其他页面
└── 全站
```

- 切换范围不清空查询文字。
- 当前文档集与当前分类只是搜索范围，不改变文档侧边栏。
- 没有当前文档集或分类时不显示无意义的空范围。
- 全站结果可以同时包含作品、文档、支持和其他公开内容，并通过路径或类型文字区分。

## 无输入与无结果

### 尚未输入

- 只显示一句简短输入提示和当前可用范围。
- 不为了填满面板显示热门搜索、搜索趋势或大批推荐链接。
- 第一阶段不保存或显示最近搜索历史。

### 没有结果

- 明确显示当前查询没有匹配结果。
- 提供清除查询、切换到更大范围或进入完整搜索页的操作。
- 不自动改写用户输入，也不展示与查询无关的推荐作品。

## 窄屏搜索

窄屏使用完整搜索界面，不把桌面命令面板压缩成狭窄浮层：

```text
[返回]  搜索作品与文档……

当前文档集   全部文档   全站
──────────────────────────

搜索结果……
```

- 输入区固定在顶部，打开后自动聚焦。
- 返回操作关闭搜索并恢复原页面与滚动位置。
- 搜索结果使用主要页面高度自然纵向滚动。
- 不显示桌面键盘快捷键提示。
- 范围入口空间不足时可以横向滚动，但不改成缺乏可见性的下拉框。
- 点击结果后直接进入目标页面。
- 打开时阻止原页面在背景中滚动。

## 主题外观

搜索结构、结果顺序与交互行为不因主题改变：

- 从首页、支持和关于打开时跟随当前浅色或深色主题，并让原有品牌环境在遮罩后轻微保留。
- 从作品、默认作品介绍页、文档和其他内容页面打开时同样跟随当前有效主题。
- 浅色与深色使用相同语义令牌层级，不分别维护两套搜索组件。
- 搜索界面不会改变或覆盖用户保存的主题偏好。
- 从品牌页面打开搜索并进入内容结果后，目标内容页面继续使用同一双主题偏好。

## 完整结果页

`/search?q={query}` 用于展示更多结果、保留查询并分享链接：

- 查询内容、范围或类型筛选同步到 URL。
- 页面使用与快速搜索一致的输入、范围命名和结果字段。
- 结果继续使用单列列表，不变成卡片墙。
- 页面本身属于双主题通用页面。
- 返回快速搜索或刷新页面后，URL 中的查询仍可恢复。

## 动效与可访问性

- 面板打开只使用轻微淡入和短距离位移，不放大整个页面或使用长时间背景缩放。
- 结果更新不能造成输入框或范围栏跳动。
- 启用 `prefers-reduced-motion` 时直接显示和隐藏。
- 搜索输入、范围切换、结果数量、当前选项和空状态需要完整屏幕阅读器语义。
- 命中摘要中的高亮不能只依赖颜色，并必须保持可读对比度。
