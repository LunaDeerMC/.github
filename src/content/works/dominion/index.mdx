## 作品介绍

Dominion 是一个开源免费的 Minecraft 领地保护插件。当前网页内容以 Dominion `4.9.1-release` 的源码、生成配置和 Paper Minecraft `26.2` 测试服行为为核对基准：领地边界、成员权限、环境规则、UI 与数据库都由服务端插件统一管理。

它适合需要清晰划分“谁能进入、谁能操作、哪些世界事件可以发生”的生存服、建筑服和多人社区。玩家不必记住所有底层规则，也可以从 ChestUI 或 Dialog 逐步完成领地管理；管理员则可以通过 YAML 文件为不同玩家组、世界和部署拓扑建立稳定的策略。

### 当前能力

- 通过手动选点或自动创建建立三维领地，支持根领地、子领地、扩缩容、重命名、删除和传送点。
- 为访客、成员、权限组和权限模板分别管理环境与交互权限；环境 flag 与权限 flag 分开处理。
- 设置进入/离开消息、地图颜色和边界显示；用 `show_border` 等规则决定玩家是否看到边界提示。
- 提供 ChestUI 与 Dialog 两种界面；玩家可以使用 `/dominion ui <chest|dialog|default>` 选择界面。
- 支持 SQLite、MySQL、MariaDB 与 PostgreSQL，并可选接入 Vault、PlaceholderAPI、WorldGuard 和 Residence 迁移。
- 通过限制文件控制玩家数量、世界数量、尺寸、垂直范围、经济收费、退款、传送冷却和子领地深度。
- 以 MIT License 免费开源，源码、发行版和问题追踪公开维护。

- [管理员文档](/docs/plugins/dominion/admin)：安装、升级、配置文件、flag、limitations、world-wide、管理员命令、集成和常见问题。

## Introduction

Dominion is an open-source, free Minecraft land-protection plugin. This page is checked against Dominion `4.9.1-release`, its generated configuration, and a live Paper Minecraft `26.2` test server: claim boundaries, member permissions, environment rules, UI, and persistence are managed by the server plugin.

It is designed for survival, building, and community servers that need a clear answer to who may enter, which actions are allowed, and which world events may happen. Players can work through Chest UI or Dialog, while administrators can express server policy through per-world and per-group YAML files.

### Current capabilities

- Create three-dimensional claims by selecting points or using automatic creation; support sub-claims, resizing, renaming, deletion, and teleport points.
- Manage environment and interaction permissions for guests, members, groups, and templates; environment and privilege flags are separate.
- Configure enter/leave messages, map colors, and boundary display behavior.
- Use either Chest UI or Dialog with `/dominion ui <chest|dialog|default>`.
- Use SQLite, MySQL, MariaDB, or PostgreSQL, with optional Vault, PlaceholderAPI, WorldGuard, and Residence migration support.
- Control claim counts, world counts, dimensions, vertical ranges, economy, refunds, teleport timing, and sub-claim depth with limitation files.
- Free and open source under the MIT License, with public source, releases, and issue tracking.

### Documentation entry points

The documentation is divided into two main chapters:

- [Player docs](/docs/plugins/dominion/player): selecting, creating, inspecting, sharing, and operating claims.
- [Administrator docs](/docs/plugins/dominion/admin): installation, configuration, flags, limitations, world-wide rules, operations, integrations, and troubleshooting.

Prefer the current commands, generated files, and server log over older materials.
