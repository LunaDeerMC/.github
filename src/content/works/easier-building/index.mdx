## Introduction

Still building walls block by block, carving mountains one swing at a time, or recalculating coordinates for a symmetrical roof? EasierBuilding handles the repetitive part between an idea and a finished structure: select a few key points in your Minecraft world, review a live preview, and then confirm the build or removal operation.

EasierBuilding is built for Paper and Folia servers and is especially suited to survival mode, where materials, tools, claims, and player builds still matter. It is not a block-spawning cheat; it is a building assistant that removes repetitive work while keeping the server's survival rules meaningful.

### From idea to structure in three steps

1. **Select**: use your crosshair to pick key positions for a line, wall, cube, or more complex shape.
2. **Preview**: inspect the full result before materials are consumed, then adjust points, variants, or replace policies as needed.
3. **Confirm**: let the smart queue place or remove blocks across multiple ticks, report progress, and pause when materials run out.

### Core capabilities

- Open the graphical interface with `/eb` to choose build modes, replace policies, modifiers, and tasks in one place.
- Use 11 build modes, including normal edit, line, wall, cube, diagonal line, diagonal wall, slope, ellipse, cylinder, sphere, and dome, covering everyday edits through large structures.
- Use mirror, linear array, and radial array modifiers to reproduce symmetrical structures, streetscape details, and circular builds; the Professional Edition also adds the Randomizer Bag for more natural large-scale surfaces.
- Follow the current mode, selection prompts, and task state through BossBar and ActionBar guidance, with timely warnings for oversized previews, missing materials, or claim protection.
- Consume inventory materials and tool durability genuinely, protect ores, dangerous blocks, and player builds, and pause safely when supplies run out.
- Respect claim-protection workflows, enforce Folia region safety, and apply configurable operation quotas for long-running survival servers.

### Basic vs. Professional

The free Basic Edition provides a complete everyday building workflow. The Professional Edition is for build teams, server builders, and players who want to complete complex structures faster, unlocking more shapes, replace policies, and duplication tools.
